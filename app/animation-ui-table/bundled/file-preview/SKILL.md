# 文件预览（File Preview）

跨 AI 通用的文件预览技能。用户给了一个文件（表格 / PPT / Word / PDF / CSV / 文本 / 图片），AI 先用本技能把内容结构化读出来，再转成用户看得懂的展示。

**为什么需要**：很多 AI 直接"看"不了 xlsx/pptx 的二进制内容，只会瞎猜或让用户自己打开。本技能用脚本把文件内容**真实解析**出来——不猜、不编造，基于解析结果回答。

## 使用流程（三步）

### 第 1 步：定位文件路径

拿到用户提供的文件（附件 / 路径 / 链接下载后的本地文件）。如果是链接，先下载到本地再解析。

### 第 2 步：运行预览脚本

```bash
python scripts/preview.py "文件完整路径"
```

可选参数：
- `--rows N`：表格最多预览多少行（默认 15）
- `--max-lines N`：文本文件最多输出多少行（默认 200）

脚本输出 **JSON**（UTF-8），结构统一为：

```json
{
  "ok": true,
  "type": "excel",
  "path": "...",
  "size": 12345,
  "preview": { ... 按类型不同的结构化内容 ... }
}
```

### 第 3 步：把 JSON 转成用户易读的展示

**禁止直接把 JSON 原样丢给用户**。按类型转换：

| 文件类型 | 用户展示方式 |
|---|---|
| Excel / CSV | Markdown 表格（表头加粗）；总行数、预览了前 N 行；sheet 多的列出每个 sheet 名称 |
| PPT | 每页一行大纲：「第 N 页：标题 + 要点」；有备注的附带备注 |
| Word | 按标题层级（H1/H2）展示大纲 + 段落要点 + 表格 |
| PDF | 每页文本摘要；页数 |
| 文本 | 直接展示内容（长文分段落） |
| 图片 | 说明图片格式/尺寸，内容描述交给 AI 的视觉能力 |

## 各类型解析能力

### Excel（.xlsx/.xlsm/.xls）
- **.xlsx/.xlsm**：列出全部 sheet 名、每个 sheet 的总行数、前 N 行数据（默认 15 行，`--rows` 可调）；单元格内容按列顺序输出（含空列占位），字符串表 / 数字 / 内联文本都支持
- **.xls（旧版二进制格式）**：同样支持！内置 OLE2 + BIFF8 解析器（纯标准库，无需额外依赖），可读出多 sheet、文本单元格、数字、公式缓存值、RK 压缩数字
- 展示时转成 Markdown 表格，表头用第一行

### PowerPoint（.pptx）
- 按页输出全部文字（标题 + 正文要点，按段落分行）
- 每页附带演讲者备注（notes）如果有
- 展示时转成「第 N 页 · 标题」大纲

### Word（.docx）
- 段落按顺序输出，识别标题层级（Heading1/2…→ H1/H2）
- 表格单独提取（每张表前 15 行）
- 展示时标题用 # 层级，正文为段落，表格转 Markdown

### PDF（.pdf）
- 优先用已安装的 pypdf / PyPDF2 / pdfplumber 提取每页文本
- **如果环境没有这些库**，脚本会返回明确提示（执行 `pip install pypdf` 即可），此时告诉用户"需要安装 pypdf 才能提取 PDF 文本"，不要假装读到了内容
- 最多提取前 30 页

### CSV / TSV
- 表格化读取，前 N 行 + 总行数，转 Markdown 表格

### 文本类（.txt/.md/.json/.py/.html/.log 等）
- 编码自动探测（UTF-8 优先，失败回退 GBK），输出前 200 行 + 总行数

### 图片（.png/.jpg/.gif/.bmp/.webp）
- 输出格式 / 尺寸（宽高像素）/ 文件大小等元信息
- **画面内容**：交给 AI 自身的视觉能力查看（本脚本不解码图片内容）

### 旧版 Office（.ppt/.doc）
- 二进制老格式（.ppt 演示文稿 / .doc 文档），脚本无法直接解析，明确提示需要先转换（或用系统的 Office 工具），**不编造内容**

## 铁律（必须遵守）

1. **内容必须来自解析结果**：JSON 里没有的，一律不得编造（比如行数、页数、文字内容）。解析失败时如实报告，不猜。
2. **给用户看的是转好的展示，不是原始 JSON**（除非用户明确要原始数据）。
3. **PDF 无库时如实说明**，不得假装提取成功。
4. 大文件 / 超长内容会被截断（单元格 300 字、文本块 1200 字、文本 200 行、表格 15 行）——展示时若带"已截断"标记，说明还有更多内容，可按需提示用户。
5. 图片内容理解依赖 AI 视觉能力；无视觉能力的环境说明"只解析到元信息"即可。
