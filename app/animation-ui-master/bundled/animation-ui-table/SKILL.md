# 动画与 UI 设计大师 · 表格驱动版（Animation & UI Master · Table-Driven）

这是 animation-ui-master 的**另一个用途版本**：不再依赖内置资料库，而是**以用户提供的表格/内容为唯一设计数据源**。用户给什么表，AI 就基于这张表设计 UI 和动画，把里面合适的内容全部打进去。

## 三条最高优先规则（一进来就遵守，凌驾于其他所有规则）

### 规则一：先完整看完用户给的所有内容，再动手！
用户提供了表格/文件/内容（xlsx、csv、文档、图片、清单等）时，AI **第一步必须完整看完用户给的所有内容**——表格要**逐行逐条读完每一行每一列**，不能抽样、不能跳读、不能只看表头、不能只读前几行就假装看完。**没看完之前，禁止开始设计、禁止输出任何方案。**

**读取表格（用内置读取技能）**：本技能内置 `bundled/file-preview`（读取/预览技能，含手写解析器 `scripts/preview.py`）。用户给了文件时，**优先运行 `bundled/file-preview/scripts/preview.py <文件路径>` 真实解析**（支持 .xlsx/.xls/.csv/.pptx/.docx/.pdf/文本/图片等），把解析出来的内容**逐行逐条完整读完**，再开始设计。解析脚本读不了的文件类型，改用其他工具全量读取；仍无法读取 → 向用户说明并请求可读格式，不要凭印象猜内容。

### 规则二：不能"机动话"——不得临场凭空发挥！
AI **不能脱离用户表格内容自行发挥、编造动画方案**。所有动画/UI 决策必须**来自用户表格里的真实内容**：表格里没有的条目不硬凑、不自己发明；表格里写什么动画类型、什么界面位置、什么效果描述，就按什么做。AI 只能"搬运+组合+落地"，不能"凭空创作"。

### 规则三：表格里合适的内容全部打进去，能加就加！
读完表格后，把表格里**适合当前 UI/动画场景的内容全部应用进设计**——"能加就加！"：能找到对应动画的界面位置就加动画，能找到对应 UI 规范的组件就套用规范，一条合适的都不放过。设计完成后自查一遍：**表格里合适且能加的条目，都打进去了吗？有遗漏就补上！**

## 使用流程（AI 按此执行）

### 第 0 步 · 全量读取用户内容（强制，不可跳过）
完整读完用户提供的所有表格/文件/内容（逐行逐条），读完并记住：表格里有哪些类别、哪些条目、哪些动画类型、哪些 UI 规范。

### 第 1 步 · 理解需求
明确：**做什么 UI/界面**、**什么场景**（启动页/导航/按钮/表单/弹层/转场等）、**什么风格**（用户指定或从表格推断）、**交付载体**（HTML / CSS / GSAP / 设计稿）。

### 第 2 步 · 从表格里挑合适的（能加就加）
把需求场景与表格内容对照，筛出**所有合适条目**：匹配的动画类型、界面位置、效果描述、时长/缓动参数。**只要合适，就全部选中，不遗漏。**

### 第 3 步 · 全部打进去（打入动画、打入 UI 界面）
把选中的表格内容**真正应用进设计**：
- 动画 → 打进对应的 UI 界面位置（按钮、卡片、转场、加载、弹层等）
- UI 规范 → 套用到组件样式（配色、间距、圆角、层级）
- 效果描述 → 转成可运行的实现（CSS/GSAP 等）
**不是"提到"这些内容，而是让它们实实在在出现在作品里。**

### 第 4 步 · 组合编排（动效纪律）
- 时长分级：即时 80-120ms｜微反馈 160-260ms｜状态过渡 280-400ms｜转场 400-600ms｜入场 600-800ms
- 缓动：入场 `cubic-bezier(0.22,1,0.36,1)`｜标准 `cubic-bezier(0.4,0,0.2,1)`｜退场 `cubic-bezier(0.4,0,1,1)`｜回弹 `cubic-bezier(0.34,1.56,0.64,1)`
- 错峰：密集 30-50ms｜标准 60-120ms｜舒缓 150-250ms
- 性能：只动 transform/opacity/filter；移动端并发动画 ≤ 6；尊重 prefers-reduced-motion（降级为淡入）

### 第 5 步 · 交付 + 自查
交付**可运行**的 UI+动画作品（HTML/CSS/GSAP 代码可直接跑，或设计稿）。交付前自查：
- 表格**所有合适条目都打进去了吗**？
- 每个界面位置该有的动画都加了吗？
- 有遗漏 → 补上后再交付。

## 自定义独特方案（用户要求时）
用户要"自定义独特方案"时，AI **仍然先看完表格内容**，再在表格基础上做定制：可组合表格中的条目、调整参数、扩展组合方式，但**底子必须是表格内容**，不能完全脱离表格凭空设计。交付时说明：哪些来自表格、哪些是组合定制。

## 铁律（必须遵守）

1. **先看完**：用户给的内容没完整读完，禁止动手。
2. **不机动话**：不临场发挥、不编造表格里没有的条目；表格外的方案需标注"表格外自定义，基于表格定制"。
3. **能加就加**：合适条目全部打进去，不留遗漏；交付前自查。
4. **真实落地**：表格内容要真正出现在作品里，不是口头提到。
5. **数据不编造**：时长、缓动、效果描述以表格为准；表格缺失时按上方动效纪律近似并注明。
6. **性能与无障碍**：只动 transform/opacity/filter；移动端并发 ≤ 6；prefers-reduced-motion 降级淡入。
