# 专业级写作技能 essay-writer（引擎驱动版）

把专业级中文写作能力复刻为**写作引擎 + 方法论指令**：结构规划、字数配比、质量检查、桌面保存由 `essay_engine.py` 代码完成，正文语言由你（LLM）按方法论生成。任何 AI 调用本技能都能产出结构完整、语言生动、字数达标的中文作文。

## 执行总流程（5 步，不可跳步）

```
① 问关键问题 → ② 引擎生成施工图(plan) → ③ 按方法论成文 → ④ 引擎质量检查(check)并回改 → ⑤ 引擎保存桌面(save) + 交付
```

引擎路径（二选一）：
- OpenClaw 环境：`{baseDir}/scripts/essay_engine.py`
- 本机环境：`scripts/essay_engine.py`

---

## Step 1 先问关键问题（写之前必须问，一次问齐）

向用户一次性列出以下问题（可附推荐默认值，用户说"随便"时替他定默认并复述确认）：

1. **主题/题目**是什么？（必填，缺则追问，不猜）
2. **要写多少字**？（默认 800；常见 400/600/800/1000）
3. **文体/风格**？（记叙文、议论文、说明文、读后感、演讲稿、散文；按主题判断默认）
4. **要不要加表情包**？（默认加；考试/正式征文默认不加）
5. **写给谁/什么场景**？（老师批改、比赛征文、公众号、演讲台）
6. **其他要求**？（引用名言、必须用比喻、指定开头等）

---

## Step 2 引擎生成施工图（plan）

运行：

```
python {baseDir}/scripts/essay_engine.py plan --topic "<主题>" --words <字数> --style <文体> --emoji on|off [--json]
```

- 输出：文体结构要点、每段角色与**目标字数**（保证"要多少字写多少字"）、语言八锦要求、表情包规范。
- 若用户文体不在支持列表，引擎自动回退记叙文并提示可选文体。
- 按施工图写：每段写到目标字数附近，主体段落详略得当。

---

## Step 3 按方法论成文（专业级语言）

### 结构（引擎已给出每段角色，遵循即可）
- 记叙文：凤头(画面感第一句) → 起因 → 经过(细节/动作/神态/心理) → 高潮 → 点题升华
- 议论文：引论亮观点 → 2-3 分论点(各举例+分析) → 结论重申展望
- 其余文体按引擎输出的施工图。

### 语言八锦（每篇至少用 3 种）
比喻、排比、拟人、对比、引用(名言/诗句)、设问、对偶、细节白描。

### 亮点句要求
- 开头第一句有画面感或悬念；
- 每段有一句"金句"（可用冒号/破折号引出）；
- 结尾一句点题 + 升华，呼应开头。

### 表情包点缀（用户选"加"时）
- 标题后 1 个、重点句后 0-1 个、结尾 1 个；全篇 **3-6 个**；
- 常用：✏️📝🎉🌟💡❤️⏳🏆；点缀不喧宾夺主；考试/正式场景不加。

---

## Step 4 引擎质量检查并回改（check）

把正文写入临时文件后运行：

```
python {baseDir}/scripts/essay_engine.py check --file <作文文件> --topic "<主题词>" --words <字数> --emoji on|off [--json]
```

检查项（引擎逐项 PASS/FAIL + 建议）：
- **字数**：目标 ±10% 内达标；不达标必须扩写/删减后重检，不许带病交付
- **重复词/口语病**：相邻重复堆叠、单字堆叠
- **分段**：3-8 段，单段不超 4 行半
- **表情包数量**：on=3-6，off=0
- **点题**：主题词须在开头段和结尾段（首尾呼应）
- **亮点句**：提示项，建议至少 1 句金句

**任一 FAIL 必须修改后重新 check，直到全 PASS 才进入保存。**

---

## Step 5 引擎保存桌面 + 交付（save）

### 5.1 保存

```
python {baseDir}/scripts/essay_engine.py save --title "<作文标题>" --file <作文文件>
```

引擎行为：探测桌面（Windows/OneDrive/macOS/Linux）→ 文件名 `作文-<今天日期>.txt` → 同名自动加序号（`作文-<日期>-2.txt`），**绝不覆盖旧作文** → UTF-8 写入 → 回读校验 → 输出路径。

### 5.2 交付告知（必须）

1. ✅ 作文已完成；
2. 告知"作文内容已放在桌面记事本上"，给出完整路径和文件名；
3. 一句话点评亮点（立意/结构/金句），问是否需要改字数或风格。

**禁止**：只在聊天里贴全文不存记事本；覆盖已有作文文件；检查未过就交付。

---

## 边界与降级

- **字数不符**（超出 ±10%）：不合格，扩写/删减后重检再交付。
- **主题缺失**：先问主题，唯一硬性必填项，不猜。
- **引擎不可用**（无 Python/脚本缺失）：按 SKILL 内"方法论速查"手工完成同等流程（自算配比、自查字数/点题），用 Write 工具手工保存桌面（同样不重名）。
- **桌面不可写**：降级保存到当前项目目录，并明确告知实际位置。
- **用户说"随便"**：替他定合理默认并复述确认后再写。

## 方法论速查（引擎不可用时的等价手工流程）

- 配比：800 字 → 开头 80-100 / 主体 3-4 段×180-200 / 结尾 80-100（按文体调整）
- 语言八锦：比喻/排比/拟人/对比/引用/设问/对偶/白描 ≥3 种
- 检查：数字数（±10%）→ 查重复词 → 查分段(3-8) → 查表情(3-6 或 0) → 查主题词是否在首尾段
- 保存：桌面 `作文-YYYY-MM-DD.txt`，同名加序号，UTF-8

- **OpenClaw 怎么装？** 把本技能目录（含 SKILL.md + scripts/）放到 `~/.openclaw/workspace/skills/essay-writer/`，或在 插件→技能→我的技能 导入 SKILL.md bundle；新开会话后用 `/essay-writer` 或直接描述触发。
- **别的 AI 怎么用？** 任何支持 OpenClaw 等技能格式的环境，导入即可；不支持的环境把 SKILL.md 作为系统指令粘贴同样可走完整流程。
- **写完想改？** 按原流程重写→重检→另存新文件（不覆盖）。
