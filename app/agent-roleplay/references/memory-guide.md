# 永不忘记忆系统 · 使用细则

本文件说明 agent-roleplay 的"全量记忆"怎么用。**核心承诺：用户说过的话，什么都记得住。**

## 记忆的三层通道

| 通道 | 时机 | 作用 |
|---|---|---|
| ① 会话内状态卡 | 扮演全程 | 在脑海中维护角色状态卡（角色/用户信息/当前场景/剧情进度/约定），每轮都带着它演 |
| ② 跨会话脚本 `scripts/memory.py` | 每轮结束、关键节点 | 把记忆**落盘**到桌面 `roleplay-memory.json`，下次会话 load 恢复 |
| ③ 自然带出 | 每 2~3 轮 | 在对话里自然提一句之前的信息（"你还说要带我去花园呢"），让用户看到你没忘 |

## 记忆脚本用法（AI 每轮强制调用）

脚本位置：`scripts/memory.py`（与 SKILL.md 同目录）。Windows 用 python 解释器执行。

| 命令 | 什么时候用 | 写什么 |
|---|---|---|
| `memory.py character <文本>` | 收集/变更角色设定 | 身份、性格、口癖、背景、关系（逐条累积，相同内容自动去重） |
| `memory.py user <文本>` | 用户说出关于自己的信息 | 用户的名字、称呼偏好、身份、口味等 |
| `memory.py pref <文本>` | 用户提出约定/规则 | "不喜欢血腥""叫我主人""别剧透"等 |
| `memory.py quote <原话>` | **每轮用户说话后** | 用户这轮说的**原文**（原样全记，不裁剪不去重——这就是"说什么都记得住"） |
| `memory.py log <事件>` | 每次剧情推进 | 剧情里发生的重要事件（全量追加，永不裁剪） |
| `memory.py summary <一句话>` | 每轮结尾 | 本轮剧情的一句话摘要（全量保留） |
| `memory.py load` | 扮演开始/跨会话恢复 | 输出全部记忆，据此接续角色 |
| `memory.py recall <关键词>` | 想确认某件事 | 按关键词检索所有记忆 |
| `memory.py clear` | 换新角色时 | 清空全部记忆，重新开始 |

## 强制规则（违反 = 失忆，禁止）

1. **用户原话必记**：每一轮用户说的话，扮演中都要用 `quote` 原样存入，不允许只记"大意"——原话比摘要更不容易失真。
2. **设定一变就更新**：用户改人设/加设定，立即 `character`/`pref` 追加；旧记录保留（可追溯），新记录为准。
3. **全量不裁剪**：记忆脚本本身不设条数上限；AI 不得手动删减记忆文件内容。
4. **开场必恢复**：进入扮演前先 `memory.py load`；若记忆里已有角色设定，直接接续上次的角色和剧情，不要重问。
5. **换角色必清空**：用户说"换个角色/重新设定"时先 `memory.py clear`，再重新收集设定，避免旧角色记忆污染新角色。
6. **3 轮自然带出**：每 2~3 轮在台词里自然引用一条记忆（约好做的事、用户说过的话、上次的剧情），证明记忆在线。

## 记忆文件

- 路径：桌面 `roleplay-memory.json`
- 内容结构：`character`（角色设定）/ `user`（用户信息）/ `prefs`（约定）/ `quotes`（用户原话，全量）/ `events`（剧情事件，全量）/ `summary`（剧情摘要）
- 跨设备/跨平台：文件跟着桌面走；在别的电脑上把该文件复制到对方桌面即可续上记忆
