# 动效 Token 规范

来源：动画大全.xlsx ③动效Token规范（43 行）。设计任何动画/UI 时先取这里的时长、缓动、间距、触发时机基准。

| 维度 | 项目 | 取值 | 说明 |
|---|---|---|---|
| 时长档位 | 即时反馈 | 80-120ms | 按下、涟漪、焦点切换，超过 150ms 会感觉迟滞 |
| 时长档位 | 微反馈 | 160-260ms | 悬停、选中、开关、回弹 |
| 时长档位 | 状态过渡 | 280-400ms | 展开折叠、值变化、Toast、错误提示 |
| 时长档位 | 转场 | 400-600ms | 路由切换、弹窗进出、共享元素 |
| 时长档位 | 入场 | 600-800ms | 首屏揭幕、模块进入视口、长列表错峰 |
| 缓动曲线 | 缓出入场 | cubic-bezier(0.22,1,0.36,1) | 元素进入，先快后慢 |
| 缓动曲线 | 标准过渡 | cubic-bezier(0.4,0,0.2,1) | 位移、颜色、尺寸一般过渡 |
| 缓动曲线 | 缓入退场 | cubic-bezier(0.4,0,1,1) | 元素离开，先慢后快 |
| 缓动曲线 | 回弹 | cubic-bezier(0.34,1.56,0.64,1) | 按压、落位、弹出，带过冲 |
| 缓动曲线 | 弹性 | cubic-bezier(0.68,-0.55,0.27,1.55) | 弹性振荡进出 |
| 缓动曲线 | 循环 | linear | spinner、shimmer、呼吸等持续动画 |
| 缓动全集 | Penner 11 族 | Back/Bounce/Circ/Cubic/Elastic/Expo/Linear/Quad/Quart/Quint/Sine | 每族含 easeIn / easeOut / easeInOut 三式，共 33 条 |
| 缓动全集 | CSS 关键字 | ease / ease-in / ease-out / ease-in-out / linear | 浏览器内置关键字 |
| 缓动全集 | 步进 | steps(n, start\|end) | 阶梯式跳变，用于序列帧 |
| 位移距离 | 微距 | 4px | 悬停上浮、按钮位移 |
| 位移距离 | 中距 | 8-16px | 入场滑入、提示滑出 |
| 位移距离 | 长距 | 24-32px | 模块进入视口、抽屉推入 |
| 错峰节奏 | 密集 | 30-50ms | 列表项、工具栏、标签等短项 |
| 错峰节奏 | 标准 | 60-120ms | 卡片网格、表单项、菜单项 |
| 错峰节奏 | 舒缓 | 150-250ms | 首屏大模块、叙事型长页面 |
| 触发模型 | load | 页面/组件挂载 | 首屏揭幕、骨架转真实内容 |
| 触发模型 | hover / focus / active | 指针与键盘 | 所有即时反馈动画 |
| 触发模型 | state-change | 数据或状态变更 | 展开折叠、增删、值变化、校验 |
| 触发模型 | scroll-into-view | IntersectionObserver | 揭示动画、数字累加、图表生长 |
| 触发模型 | scroll-driven | 滚动进度映射 | 视差、进度条、路径描边、吸顶 |
| 触发模型 | route-change | 路由/视图切换 | 转场、共享元素、滚动位置恢复 |
| 触发模型 | gesture | 指针/触摸/手势 | 拖拽、长按、捏合、滑动 |
| 触发模型 | audio-driven | Web Audio API | 频谱、波形、节拍驱动 |
| 物理参数 | 弹簧 stiffness | 100-300 | 数值越大越硬越快 |
| 物理参数 | 弹簧 damping | 10-30 | 数值越大越阻尼越少过冲 |
| 物理参数 | 弹簧 mass | 0.5-2 | 质量越大越沉 |
| 物理参数 | 惯性衰减 | 0.92-0.98 | 每帧速度衰减系数 |
| 物理参数 | 重力加速度 | 900-2000 px/s² | 下落类动画 |
| 性能红线 | 合成层属性 | 只动 transform / opacity / filter | 禁止动画 width/height/top/left |
| 性能红线 | 滚动节流 | rAF + IntersectionObserver | 禁止 scroll 内同步读布局 |
| 性能红线 | 移动端 | 视差与粒子降级或关闭 | 低端机并发动画 ≤ 6 |
| 性能红线 | 可访问性 | prefers-reduced-motion | 关视差/弹簧/自动播放，仅留淡入 |
| 工程约定 | 打断续接 | 从当前计算值续接 | 禁止打断跳回初始帧 |
| 工程约定 | 变换空间 | 进出场同一变换空间 | 避免位移方向/距离不一致 |
| 工程约定 | 去重 | once 标志 + 卸载解绑 | 揭示动画只播一次；路由清理旧监听 |
| 工程约定 | 命名规范 | ANM-XXXXX / TYP-XXXX | 总表与百科编号互查 |
| 工程约定 | 层级区分 | 独立动画层 / 参数手段层 | 缓动与属性是实现手段，非独立动画类型 |
